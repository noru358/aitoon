# Research inputs

`reference_data/korean_instatoon_benchmark_v0.1.jsonl` is a dated starter
benchmark copied from read-only `noru358/AutoPipeline` commit `81c40a1`.

Use it for format grammar, production decisions, abstraction, staging and source
discovery leads. Do not use it as:

- an image-training dataset;
- permission to imitate one living artist;
- proof that dated follower/view counts remain current;
- a substitute for directly inspecting the source selected for a new episode.

The architecture's “human-drawn” target comes from cross-reference principles
and bound project references, not cloning one account.
